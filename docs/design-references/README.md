# Design references

Two DESIGN.md analyses from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, see `LICENSE`), copied at commit fcc7028. They are **reference material**, not the brand.

- `apple.md`: photography first presentation, generous whitespace, one pill action, one shadow reserved for the product.
- `oura.md`: warm paper canvas, large light serif headlines with a quiet sans, soft rounded cards and pill tabs.

What Verdane takes from them, and what it keeps from its own brand, is written in `DESIGN.md` (section 7). Fonts, colours and the all ivory page always follow `DESIGN.md` and `CLAUDE.md`, never these files.
