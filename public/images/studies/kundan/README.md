# Kundan, in window light

Upload any one of these files to this folder on the site's deployment branch. Use the real file extension. WebP, JPG, JPEG, PNG and AVIF are supported. Keep one extension per name.

| Filename example | Photograph | Suggested crop |
| --- | --- | --- |
| `detail.webp` | Close view of the setting | Landscape, with the detail near the centre |
| `portrait.jpg` | Jewellery on a model | Vertical, leaving room around the face and jewellery |
| `still-life.webp` | The whole piece arranged on a surface | Vertical, with space around the piece |
| `setup.jpg` | Optional behind-the-scenes lighting setup | Landscape |

Each file replaces only its own reference after the next deployment. The homepage, portfolio and study page read from this folder. The reference label disappears for that frame. The lighting diagram stays visible until a setup photograph is added.

For more precise descriptions, edit the subject alt text in `lib/kundan-study.ts`. Credit collaborators on the study page when their names are ready.
